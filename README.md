# Estrutura de Dados — Pilhas

Repositório destinado à apresentação do trabalho da disciplina de **Estrutura de Dados**, do curso de Análise e Desenvolvimento de Sistemas (ADS) do Instituto Federal do Piauí (IFPI).

O trabalho consiste na resolução e explicação de duas questões do capítulo 2, utilizando pilhas implementadas na linguagem C.

## Questão 2.3 — Inversão de palavras

Programa que utiliza uma pilha para inverter as letras de cada palavra de uma frase, preservando a ordem original das palavras.

**Arquivos:**
- [Código-fonte](questao-2.3/questao_2_3.c)
- [Vídeo explicativo](questao-2.3/video_questao_2_3.mp4)

## Questão 2.5 — Expressões balanceadas

Programa que utiliza uma pilha para verificar se uma expressão contendo parênteses, colchetes e chaves está corretamente balanceada.

**Arquivos:**
- [Código-fonte](questao-2.5/questao_2_5.c)
- [Vídeo explicativo](questao-2.5/video_questao_2_5.mp4)

## Conteúdo dos vídeos

Cada apresentação contém:
1. Leitura do enunciado.
2. Explicação teórica da solução.
3. Apresentação e explicação do código em C.
4. Demonstração do funcionamento no terminal.
